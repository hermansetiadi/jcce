# JCCE-11121 — Code and data

Reproducibility bundle for the manuscript *Training-Subset Curation for
Low-Data Paddy-Field Segmentation Using Landscape Metrics and
Background-Dominated Tiles* (Setiadi, Irwansyah, Arifin & Zarlis).

Every result in the paper was produced by one pipeline, under one
protocol version, on the environment recorded in `env/`.

## Layout

```
code/         experiment pipeline (Python)
manifests/    spatial split + protocol stamps that define the run
results/      per-arm metrics as JSON (the numbers behind every table)
figures/      manuscript figures (vector PDF + PNG)
env/          exact package list and hardware/driver record
RUN_INSTRUCTIONS.md   full run guide, resume behaviour, troubleshooting
```

## Run it

```bash
python code/RUN_ALL.py --log-dir C:\jcce_logs
```

`RUN_ALL.py` runs every stage in dependency order, stamps each with the
protocol version that produced it, and resumes cleanly after an
interruption. See `RUN_INSTRUCTIONS.md` for the smoke test (`--quick`),
per-stage flags, and the eight-seed paired analysis.

## What each results directory holds

| directory | stage | key file |
| :--- | :--- | :--- |
| `outputs/` | single-region pilot | `test_metrics.json` |
| `outputs_multiregion/` | pooled + cross-region | `pooled_metrics.json` |
| `outputs_dataefficiency/` | budget-matched K sweep (Table 2) | `efficiency_metrics.json` |
| `outputs_selection/` | selection strategies (Table 4) | `selection_metrics.json` |
| `outputs_domain_adapt/` | cross-region transfer (Table 7) | `domain_adapt_metrics.json` |
| `outputs_ablation/` | resolution + backbone (Table 6) | `ablation_metrics.json` |
| `outputs_landscape/` | image-only proxy (Table 5) | `proxy_correlation.json` |
| `outputs_protocol/` | measurement-defect quantification (§5.1) | `partition_separation.json` |

The eight-seed paired comparison behind Table 2 (continued) is in
`outputs_dataefficiency/paired_effect_*.json`.

## Environment

`env/environment.txt` and `env/requirements_frozen.txt` record the exact
Python, PyTorch, CUDA/cuDNN, GPU and package versions used. Randomness is
seeded and cuDNN runs deterministically; the split RNG is scoped per
region.

## Not included

Trained model checkpoints (`best_*.pt`) are omitted deliberately: they are
regenerated by the pipeline and would only bloat the repository. Raw
imagery and masks are released separately (Mendeley Data / figshare; see
the manuscript's Data Availability Statement).
